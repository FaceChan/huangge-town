景致

莲溪天后古庙

八百年香火 · 广东四大名庙之一

始建于南宋咸淳九年（1273 年），与佛山祖庙、德庆悦城龙母庙、黄埔南海神庙并称，是黄阁最古老的天后古庙。

古庙 / 天后 / 历史

麦氏大宗祠

宋代始建 · 广州三大宗祠之一

始建于宋代、距今约九百年的麦氏大宗祠，是广州仅次于陈家祠、沙湾留耕堂的第三大宗祠，2004 年列为广州市重点文保单位。

祠堂 / 建筑 / 历史

大井村 · 蚝壳墙与老榕

在古村落里听时间慢下来

成片的蚝壳墙在阳光下泛着细密的光，根须垂落的老榕遮出大片阴凉。这是黄阁最古老村落之一，适合慢慢走。

村落 / 水乡

黄阁古街

八百年老街的新老对话

相传黄阁先祖最早定居于此，距今已有八百年。古祠堂、东里红楼、广升楼与风格各异的新房交错，新老有机共存。

古街 / 建筑 / 休闲

大山乸

南沙第二高峰 · 一览蕉门与明珠湾

大山乸是南沙区内第二高峰，登顶可纵观蕉门河中心区与明珠湾起步区，是俯瞰南沙新区的绝佳观景点。

山景 / 森林 / 观景

南沙汽车码头

亚洲最大汽车滚装码头

位于黄阁镇沙仔岛，是亚洲最大的汽车滚装码头、国家一类对外开放口岸，场面磅礴，工业景观别具一格。

工业 / 码头 / 景观

黄阁麒麟文化展示馆

广州唯一 · 走进麒麟的百年世界

由清代瑞辉麦公祠改造而成，是广州市唯一一个全面反映麒麟文化发展与变迁历程的展示馆，汇集历史、风土与大量麒麟展品。

文化 / 非遗 / 展馆

蕉门水道 · 江畔黄昏

在珠江口的水道上等一场落日

蕉门水道穿镇而过，江风、滩涂与归鸟构成黄阁最烟火气的水乡景致。沿江步道适合骑行与散步。
